# Code of conduct

Be respectful, constructive and considerate of other people's time. Critique
ideas and code, not people. Harassment, discrimination, threats, sharing private
information and deliberate disruption are not welcome.

Maintainers may edit or remove contributions, close discussions, or restrict
participation to protect the community. Enforcement should be proportionate and
consistent. Report concerns privately through the repository owner's GitHub
profile or, for security concerns, the process in SECURITY.md.
