# 0.1.0 release review

Scope: the complete first release, including protocol, session state, terminal UI,
packaging, documentation and CI. Independent read-only reviews covered lifecycle
and state, and keyboard/layout/request behavior. The main implementation pass
triaged and fixed each finding.

| Finding                                                                 | Disposition | Resolution                                                                          |
| ----------------------------------------------------------------------- | ----------- | ----------------------------------------------------------------------------------- |
| Quit during initialization could still submit the initial prompt        | FIX         | Cancellable launch boundary; stop connection immediately; regression test           |
| Shutdown callers could return before owned processes exited             | FIX         | One shared shutdown promise, bounded graceful exit and forced cleanup               |
| History hydration could put older messages after streamed messages      | FIX         | Snapshot ordering reconciled separately from content revisions; regression test     |
| Resumed workspace could differ from UI/export paths                     | FIX         | Server-returned cwd owns effective workspace; explicit resume/cwd conflict rejected |
| Local save or prompt failure falsely marked healthy server disconnected | FIX         | Transport and local errors handled separately; regression test                      |
| Pending requests hid quit confirmation while its keys remained active   | FIX         | Shared input/render precedence; visible full-screen confirmation                    |
| Small terminals hid approval choices                                    | FIX         | Bounded full-screen request layout with fixed control rows; 40x16 assertion         |
| Interrupt shortcut erased an unsent draft                               | FIX         | Command consumption separated from shortcuts; cancel regression test                |
| Background requests captured composer input and could not be deferred   | FIX         | Explicit Ctrl+R request focus and Esc defer; no automatic focus stealing            |
| Question/form editor discarded cursor state                             | FIX         | Per-request editor state and grapheme cursor                                        |
| Delete behaved as Backspace                                             | FIX         | Separate forward/backward deletion; Unicode regression test                         |

Follow-up finding: MCP form defer discarded its draft. **FIX:** per-request form
state now survives Esc and menu navigation, with a regression test.

## Deliberate product boundaries

The owner selected the official-engine scope: native child inspection, approval
handling and interruption. Direct V2 child messages are disabled by Codex itself;
no parent-message relay, metadata manipulation or engine fork is substituted.

The terminal client implements its documented commands, not every stock Codex UI
feature. No automatic compaction, telemetry or credential duplication is added.
The reviewers rechecked their original findings; all were resolved. The final
MCP form follow-up was fixed and covered by a regression test. There are no
untriaged review findings in the table above.
