# 0.2.1 release review

Status: local verification complete; publication requires successful CI on the
exact release commit.

## Scope

Make native subagent navigation work in VS Code's integrated terminal and allow
pointer selection from the visible agent strip. The change stays in the TUI and
uses native thread selection, modal ownership, and composer handling.

## Findings

- VS Code sends Ctrl+arrow terminal events for Alt+arrow input. The native
  navigation matcher now accepts both forms.
- The strip records rendered row bounds and native thread IDs. Hover highlights
  a visible row; left click selects that thread through the existing App path.
- Overlays and dialogs retain mouse priority. An integration test covers a draft
  in the composer during agent selection.
- No model, permission, migration, or daemon behavior changes are included.
