# Native migration review

Status: reviewed; local verification recorded below. Publication requires successful CI on the exact release commit.

## Scope

Replace the 0.1 App Server frontend with pinned Codex 0.157.1 source, native welcome
and subagent presentation, and a Node installer/launcher. Keep native commands,
navigation, permissions, approvals, conversation persistence and interruption.
Review the native patch separately from the mechanical upstream import and the
bootstrap/distribution change. Independent native and installer reviews were
read-only; coupled fixes were applied in the main working tree.

## Findings and disposition

| Finding | Disposition |

| Windows standalone updater dispatched a fork command through PowerShell incorrectly | FIX: use the shared native update command path |

| Signal forwarding did not mirror child termination | FIX: remove listeners and propagate the terminating signal |
| Linux build omitted the bundled sandbox digest | FIX: derive compile-time digest from the pinned platform payload and verify it during packaging |
| Windows SQLx source checksums differed | FIX: reproduce official target source line endings; leave databases and runtime checks intact |

## Validation

Bootstrap: 15 cases, 14 passed and the Unix symlink case skipped on Windows.
Initial full native run: 5,802 passed, 61 failed, one timed out, 11 skipped; passed
cases include 285 leaky cases and one retry success. Raw output is retained locally.
Do not interpret these counts as release acceptance.

Second full run: 5,847 passed, eight failed, 12 timed out, 11 skipped. No stack
overflows remained; the 16 MiB test stack was sufficient. Six deterministic layout
failures were reproduced serially with ANSI forced and traced to the synthetic
terminal's stale size override. The other failures were deadline-related. The
next full run uses two concurrent tests without weakening assertions or timeouts.

Third full run: 5,864 passed, two failed, one timed out, 11 skipped. All three
remaining cases and the affected UI/resize families were then rerun after fixes:
61 passed, zero failures (21 cases reported leaky handles). Snapshot updates were
disabled. Scoped `just fix -p codex-tui -p codex-cli --profile dev-small` and
`just fmt` completed successfully.

The Windows trust regression was reproduced with an actual 8.3 temporary path.
All 348 configuration tests and nine affected CLI/TUI tests passed across two
runs (356 + 1 cases). Coverage includes trusted and untrusted identities,
verbatim compatibility and conflicting-key precedence. No configuration schema
fields or policy defaults changed.

The isolated Windows package launched using the existing Codex data. Real PTY
input verified the centered welcome after model initialization, native slash and
model pickers, a real child appearing in the strip, Alt+Down into the child,
Alt+Up back to its parent, and Escape interrupting a running child. The native
interruption notice appeared and the strip changed to idle. Both acceptance
sessions exited cleanly. The acceptance task was restricted to timed waits.

The first Linux CI run passed 5,943 of 5,945 tests. Its remaining failures were
the subsequently corrected synthetic-resize fixture and missing system bwrap.
Every release must reuse successful CI artifacts from its exact source commit.
The release includes `validation.json` linking that successful run; this is the
authoritative cross-platform acceptance record, alongside its checksum manifest.

## Removed and retained

Removed the TypeScript chat UI, command handling, independent agent state, obsolete
tests and synthetic screenshots. Historical 0.1 review/validation remains labeled
as historical. The official platform resource tree and Apache notices are retained
in full. No database resets, migration-check bypasses or model/permission policy
changes are used.
