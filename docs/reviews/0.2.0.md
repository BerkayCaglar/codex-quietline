# Native migration review

Status: implementation complete; final native regression and release validation in progress.

## Scope

Replace the 0.1 App Server frontend with pinned Codex 0.157.1 source, native welcome
and subagent presentation, and a Node installer/launcher. Keep native commands,
navigation, permissions, approvals, conversation persistence and interruption.
Review the native patch separately from the mechanical upstream import and the
bootstrap/distribution change. Independent native and installer reviews were
read-only; coupled fixes were applied in the main working tree.

## Validation

Bootstrap: 14 cases, 13 passed and the Unix symlink case skipped on Windows.
Initial full native run: 5,802 passed, 61 failed, one timed out, 11 skipped; passed
cases include 285 leaky cases and one retry success. Raw output is retained locally.
Do not interpret these counts as release acceptance.

Second full run: 5,847 passed, eight failed, 12 timed out, 11 skipped. No stack
overflows remained; the 16 MiB test stack was sufficient. Six deterministic layout
failures were reproduced serially with ANSI forced and traced to the synthetic
terminal's stale size override. The other failures were deadline-related. The
next full run uses two concurrent tests without weakening assertions or timeouts.

The isolated Windows package launched with the existing Codex data after source
byte correction. Native slash/model menus and clean exit were exercised with real
PTY input. Final-build interaction, normal snapshot verification, scoped Clippy,
cross-platform CI artifacts, public release and installed-command verification
remain to be recorded before release completion.

## Removed and retained

Removed the TypeScript chat UI, command handling, independent agent state, obsolete
tests and synthetic screenshots. Historical 0.1 review/validation remains labeled
as historical. The official platform resource tree and Apache notices are retained
in full. No database resets, migration-check bypasses or model/permission policy
changes are used.
